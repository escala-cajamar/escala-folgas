# Escala de folgas

Escala de folgas de 2027, mês a mês (turnos da manhã e da tarde), seguindo o ciclo de 2 semanas iniciado em 04/01.

Página: https://ronnyjd00-alt.github.io/escala-folgas/

O preenchimento fica salvo no navegador de cada computador. Use "Exportar arquivo" e "Importar arquivo" para levar a escala de um computador para outro.
